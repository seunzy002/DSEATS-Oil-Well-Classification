# DSEATS-Oil-Well-Classification
A Project using Rule based and Machine learning Algorithm for Well Classification

Rule-based Algorithm was first used to classify the well into respective Labels.

Used CatBoost ML Algorithm 

Minimal preprocessing required — ideal for well classification

80% of data was used for training(16wells) and 20% as test data(4 wells)

Model trained on key reservoir and production features

New Features based on well statistics were Engineered to capture trends

Achieved ≥ 0.99 on evaluation metrics

Evaluation Metrics used are accuracy, precision, recall & F1-Score
